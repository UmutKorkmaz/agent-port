# Support Policy

AgentPort support plans include help with onboarding, document ingestion, model route setup, and local deployment checks.

Refunds are available within 14 days of purchase when the customer has not used more than 100 production agent requests. Refund requests must include the workspace id, invoice id, and a short reason. Approved refunds are returned to the original payment method.

Enterprise customers can request a manual review for billing disputes, data residency questions, and private model route configuration.

Public chat widgets should use scoped API keys, domain allowlists, and rate limits before production use.
