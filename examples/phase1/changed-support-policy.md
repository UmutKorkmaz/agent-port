# Support Policy

AgentPort support plans include help with onboarding, document ingestion, model route setup, trace review, and local deployment checks.

Refunds are available within 30 days of purchase when the customer has not used more than 100 production agent requests. Refund requests must include the workspace id, invoice id, and a short reason. Approved refunds are returned to the original payment method.

Enterprise customers can request a manual review for billing disputes, data residency questions, private model route configuration, and widget rollout planning.

Public chat widgets should use scoped session tokens, domain allowlists, and rate limits before production use.
